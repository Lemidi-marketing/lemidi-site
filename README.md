# lemidi.com.br

Site institucional da Lemidi Inteligência Digital, publicado na Netlify a partir desta pasta.

- `site/` é o site publicado: cada página é um `index.html` dentro da pasta do seu endereço (ex.: `site/odontologia/index.html` → lemidi.com.br/odontologia/).
- `site/assets/img/` guarda as imagens.
- `site/_redirects` leva os endereços do site antigo (WordPress) para as páginas novas.
- `site/robots.txt` está bloqueando a indexação enquanto o site roda só no endereço de teste. Na troca de domínio, substituir pelo conteúdo de `robots.prod.txt`.
